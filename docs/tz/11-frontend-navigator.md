# 11. Фронт — модуль 2 «Инвестиционный навигатор»

**Кому:** фронт. **Папка:** `frontend/`. Контракт — [08-product2-contract.md](08-product2-contract.md), примеры ответов —
`contracts/examples/` (`projects.json`, `project.json`, `timeline.json`, `related-companies.json`, `subscriptions.json`,
`notifications.json`, `telegram-link.json`, `locations.json`). Общие правила (вход, `apiFetch`, ошибки, бренд,
брейкпоинты) — как в продукте 1, [01-frontend.md](01-frontend.md).

**Главное:** бэкенд продукта 2 **уже работает** в `main` — все эндпоинты ниже отвечают на настоящих данных.
Можно сразу ходить в API (`docker compose --profile product2 up -d --build`); MSW — только для работы без бэкенда.

**Зачем экран:** менеджер видит инвестпроекты области, **что из услуг Ростелекома им нужно** и **какие компании
рядом** — потенциальные клиенты; подписывается на район / отрасль и получает уведомление о новом проекте.

## Данные — что увидит пользователь

63 проекта; стадии: проектирование 8, строительство 34, запуск 21; отрасли — 9 из справочника; у каждого проекта
есть потребности и рекомендации услуг. Годы старта 2019–2026, запуска 2026–2055 (один проект — 2055, см. таймлайн).
Координат у проекта нет — только муниципалитет: `lat`/`lon` = центр района; **в одном районе несколько проектов**
(в Ростове — больше половины).

## 1. Маршрут и шапка

- Маршрут `/navigator` (под `RequireAuth`, как `/`). Шапка: «Радар присутствия» | **«Навигатор»** — вкладки,
  активная выделена; пункт «Навигатор» больше не неактивный.
- В шапке — колокольчик с числом непрочитанных (`unreadCount`), см. раздел 6.
- Код-сплиттинг: страницу Навигатора грузить лениво (`React.lazy` + `Suspense`) — бандл уже 1 МБ, на телефоне это
  заметно.

## 2. Фильтр = URL (как `CompanyFilter`)

Отдельный хук и одна функция `projectFilterToQuery()` для списка, таймлайна, карты (и экспорта, когда будет).

| Параметр | Значения | UI |
| --- | --- | --- |
| `stage` | мульти: `design` `construction` `launch` | чипы «Проектирование / Строительство / Запуск» |
| `industry` | мульти, коды отраслей (как в радаре) | мультиселект |
| `need` | мульти: `it_infra` `apcs` `phys_security` `info_security` | чипы потребностей |
| `municipalityId` | мульти, int | мультиселект с поиском |
| `yearFrom`, `yearTo` | год | диапазон на таймлайне (раздел 4) |
| `isKey` | `true` | флажок «Только ключевые» |
| `amountMin` | млн ₽ | поле «Объём от, млн ₽» |
| `q` | ≥ 2 символов | поиск по названию и инициатору |

Справочники `stages`, `needs` — уже в `GET /api/dictionaries` (`staleTime: Infinity`, как сейчас). Неизвестный код →
400 `VALIDATION_ERROR` с `details.field` — показать тостом. Дебаунс 300 мс, `replace`, ключ кэша = строка фильтра.

## 3. Экран и раскладка

- **Десктоп ≥ 1280:** фильтры | карта, над ней таймлайн | список проектов. **Планшет:** фильтры в выезжающей панели.
- **Телефон < 768:** вкладки «Карта / Список», таймлайн — горизонтальная лента над картой с прокруткой пальцем;
  фильтры — нижняя выезжающая панель (как в радаре).
- **Карта** (та же MapLibre-подложка): маркер на **район**, а не на проект — кружок с числом проектов под фильтром,
  цвет по преобладающей стадии; клик → список фильтруется по району (`municipalityId`), карта приближается.
  Выбранный проект подсвечен. Легенда стадий.
- **Цвета стадий** — из палитры бренда, не путать с «наши / не наши» радара: проектирование — `--rt-blue`,
  строительство — `--rt-purple`, запуск — `--rt-gray`.
- **Список:** `GET /api/projects?<фильтр>&page&size&sort` → `{ items, page, size, total }`. Сортировки: объём
  (по умолчанию `amountMln,desc`), рабочие места, год старта, год запуска, название. Строка: название, инициатор,
  район, стадия (чип), объём «X млн ₽», годы «2024–2028», значок «ключевой». «Найдено: N». Пусто → «Проектов
  по этим условиям нет — ослабьте фильтры».

## 4. Таймлайн

`GET /api/projects/timeline?<тот же фильтр>` →
`{ minYear, maxYear, total, years: [{ year, events: [{ projectId, type: start|launch, title, municipalityId, municipalityName, stage, amountMln }] }] }`.

- Горизонтальная шкала по годам; на году — точки событий: «старт» и «запуск» разными значками; размер ~ `amountMln`.
- Наведение (на телефоне — тап) → подсказка: название, район, объём. Клик → проект подсвечен в списке и на карте,
  открывается карточка.
- **Выбор диапазона** (перетаскивание или два ползунка) → `yearFrom` / `yearTo` в URL, список и карта
  обновляются вместе.
- Длинный хвост: один проект запускается в 2055 — не растягивать шкалу. Показывать до 2035, всё позже — одним
  блоком «2036+».
- `total` — число проектов под фильтром (не событий).

## 5. Карточка проекта (drawer, как карточка компании)

`GET /api/projects/{id}` → `Project`; 404 → «Проект не найден».

1. Заголовок, инициатор, район, стадия, годы, объём (млн ₽), рабочие места, куратор, «ключевой».
2. **«Что предложить Ростелекому»** — главный блок экрана: `recommendedOffers` — по потребностям
   (`needName`) списки `offers`. Акцентно (лавандовая подложка, фиолетовый заголовок).
3. **«Компании рядом»** — `GET /api/projects/{id}/related-companies` (грузить при открытии карточки) →
   `{ items, sameAreaIndustryTotal, radarQuery }`:
   - `relation = initiator` — первым, бейдж «Инициатор проекта» (если найден в реестре);
   - `relation = same_area_industry` — до 20 компаний той же отрасли в районе, **сначала не клиенты**;
     цвет по `kind` (как в радаре), выручка с бейджем «оценка» / «ФНС»; клик → карточка компании (уже есть);
   - «Всего в районе по отрасли: N» (`sameAreaIndustryTotal`) и кнопка **«Открыть в радаре»** →
     переход на `/?{radarQuery}` (радар с фильтром района и отрасли). `radarQuery = null` → кнопку не показывать.
4. Кнопка **«Подписаться на такие проекты»** → `POST /api/subscriptions` с `industry` и `municipalityId` проекта
   (раздел 6); после — тост «Подписка оформлена».

## 6. Подписки и уведомления (сервис notifier, через nginx те же `/api/...`)

- **Колокольчик в шапке:** `GET /api/notifications` раз в 60 с (и при фокусе вкладки) → число `unreadCount` на значке.
  Клик → выпадающий список последних уведомлений: название, район, время; клик по уведомлению →
  `POST /api/notifications/{id}/read` и открыть карточку проекта (`projectId`). «Прочитать все» →
  `POST /api/notifications/read-all`.
- **Экран «Подписки»** (из меню пользователя или ссылкой из колокольчика):
  - список `GET /api/subscriptions` — каждая подписка человеческим текстом: «Логистика · г. Ростов-на-Дону»,
    «Физическая безопасность · стадия Строительство»; «Отписаться» → `DELETE /api/subscriptions/{id}`;
  - форма «Новая подписка»: отрасль, район, потребность, стадия — **хотя бы одно поле**; пустая форма → кнопка
    неактивна; ответ 400 → текст из `error.message`;
  - **Telegram:** `GET /api/notifications/telegram-link` → `{ botConfigured, linked, url }`:
    `botConfigured = false` → «Telegram не подключён на сервере» (кнопки нет);
    `linked = false` → кнопка «Подключить Telegram» (открывает `url` в новой вкладке — это `t.me/…?start=…`);
    `linked = true` → «Уведомления приходят в Telegram ✓».
- В ленту попадают только проекты, появившиеся **после** создания подписки — это нормально, не баг.

## 7. Что разблокировал бэкенд в продукте 1 (тоже сделать)

- **Админ: «Обновить список клиентов»** (кнопка видна при роли `admin` в `user.roles`): диалог выбора CSV
  (до 10 МБ) и режима «Добавить / Заменить» → `POST /api/clients/import` (`multipart/form-data`: `file`, `mode`) →
  показать `{ rows, matched, notFound, whiteSpots }` («Загружено 41, найдено 40, не найдено 1: …; белых пятен: 2»).
  После успеха — инвалидировать карту, список, статистику районов, белые пятна. 413 → «Файл больше 10 МБ».
- **Задача со звёздочкой** ([07](07-star-actual-location.md)) — фильтр `relocated` и чипы у вас уже есть, осталось:
  - карточка компании, блок **«Где работает»**: `GET /api/companies/{id}/locations` →
    `{ registered, actual[], relocated }` — регистрация и фактические места с источником и уверенностью;
  - кнопка **«Указать фактическое место»**: район/город из справочника **или** «другой регион» (текст), адрес,
    комментарий → `POST /api/companies/{id}/locations` (201); удалить своё — `DELETE …/locations/{locationId}`;
  - в списке — значок «работает в другом месте» у `relocated: true`;
  - на карте у выбранной компании — пунктир от точки регистрации к фактической.

## 8. Экспорт проектов

`GET /api/export/projects` делает C# после экспорта компаний — кнопку «В CSV» в Навигаторе добавить, когда эндпоинт
появится (тот же `downloadBlob`, имя файла из `Content-Disposition`).

## Демо-сценарий модуля 2 (по нему проверяем)

1. «Навигатор» → карта районов с проектами и таймлайн 2019–2035.
2. Фильтр «Производство» → таймлайн, карта и список меняются вместе.
3. Таймлайн: диапазон 2026–2028 → только проекты, которые идут в эти годы.
4. Карточка «Строительство тракторного завода» → блок «Что предложить» (АСУ ТП, ИТ-инфраструктура) →
   «Компании рядом» → «Открыть в радаре» → радар с фильтром района и отрасли.
5. «Подписаться на такие проекты» → (демонстратор запускает новый проект) → колокольчик «1» → уведомление →
   карточка нового проекта. Если бот настроен — то же сообщение в Telegram.
6. Всё то же на телефоне.

Демонстратор на шаге 5: `docker compose exec etl python -m etl demo-project` и ручная проверка notifier
(команда — в `docs/tz/10-java-todo.md`, раздел 1) — уведомление появится без ожидания минуты.

## Готово, когда

Сценарий проходит на телефоне и в трёх браузерах (Chrome, Firefox, Яндекс) на настоящем API в образе nginx после
`docker compose --profile product2 up -d --build`; фильтр Навигатора живёт в URL (ссылкой можно поделиться);
