# 01. Фронт — React SPA

**Владелец:** фронтенд-разработчик. **Папка:** `frontend/`. **БД:** нет — только `/api/*` через nginx.
**Сборка:** образ nginx собирает фронт сам (`infra/nginx/Dockerfile`: `npm ci && npm run build` → `dist/`).
Обязательны `package.json`, `package-lock.json` и скрипт `build`, кладущий результат в `dist/`.

**Стек:** React 18 + TypeScript + Vite, React Router, TanStack Query, MapLibre GL (или Leaflet), MSW для заглушек.
Запросы — относительные (`/api/...`), без хоста.

## Что сказал куратор — и что это значит для интерфейса

| Куратор | Интерфейс |
| --- | --- |
| Выручка «от … до» | два поля диапазона (в млн руб.) или двойной слайдер |
| Локация — или вариант с приближением карты, «как выбор ПВЗ при доставке» | карта с кластерами; список справа показывает только то, что в окне карты; плюс выбор района из списка |
| Обязательно отрасль | мультиселект отраслей |
| Наш / не наш: только наши, только не наши, все — и разные цвета | переключатель из трёх кнопок; на карте наши — фиолетовым, не наши — оранжевым, в «Все» кластер показывает долю обоих |
| В файле есть закрывшиеся | переключатель «Показывать исключённых из реестра» (`status=all`) — серым, по умолчанию выключен |

## Продукт 1 — что сделать

### 1. Каркас и бренд

- [ ] CSS-переменные: `--rt-purple: #7700FF` (наши, основной), `--rt-orange: #FF4F12` (не наши, акцент), серый
      `--rt-gray` (исключённые), текст, фон. **Точные цвета и шрифт сверить с брендбуком** (попросить у куратора);
      пока — значения со слайдов кейса и Inter/системный шрифт.
- [ ] Шапка: логотип, «Радар присутствия» / «Навигатор» (неактивен до продукта 2), пользователь, «Выйти».
- [ ] Брейкпоинты: телефон < 768, планшет 768–1279, десктоп ≥ 1280. Проверять в Chrome, Firefox, Яндекс.Браузере.

### 2. Вход с 2FA

```
/login ──(email+пароль)──► POST /api/auth/login
   │                         ├─ 401 → «Неверный email или пароль»
   │                         └─ 200 { mfaToken, mfaSetupRequired, qrPngBase64? }
   ▼
/login/2fa  (mfaToken — только в памяти)
   ├─ mfaSetupRequired → показать QR (<img src="data:image/png;base64,…">) + «Отсканируйте в Google/Яндекс Аутентификаторе»
   └─ 6 цифр (inputmode="numeric", autocomplete="one-time-code", автосабмит на 6-й цифре)
         ──► POST /api/auth/2fa/verify { mfaToken, code }
               ├─ 401 INVALID_CODE → «Неверный код», очистить поле
               ├─ 429 → «Слишком много попыток», назад на /login
               └─ 200 { accessToken, expiresIn, user } → сохранить → на /
```

- [ ] Токен: память + `sessionStorage` (обёртки в `try/catch`).
- [ ] Один `apiFetch()`: подставляет `Authorization`; на любой 401 — очистить токен, на `/login?next=…`; ошибки — в `{ code, message }`.

### 3. Фильтр = URL

- [ ] Источник правды — query-строка, параметры ровно как `CompanyFilter` (см. 00-common).
- [ ] Контрол → URL через `replace` с дебаунсом 300 мс; **движение карты** → `minLat/maxLat/minLon/maxLon` с дебаунсом
      400 мс после `moveend` (округлять до 4 знаков, чтобы не плодить кэш).
- [ ] Одна функция `filterToQuery()` — для карты, списка и экспорта: экспорт гарантированно совпадает с экраном.
- [ ] Ключ кэша TanStack Query = эта строка (+ `zoom` для карты); старые данные показываем полупрозрачно, пока грузятся новые.

### 4. Карта «как выбор ПВЗ»

Один источник — `GET /api/map/cells?<фильтр>&zoom=<целый зум>`. Сервер сам решает, что вернуть:

```json
{ "mode": "cells", "cellDeg": 0.656, "total": 182344,
  "cells": [ { "lat": 47.2311, "lon": 39.7102, "total": 5120, "ours": 210, "others": 4910, "excluded": 0 } ] }
```

```json
{ "mode": "points", "total": 312,
  "points": [ { "id": 101, "lat": 47.1102, "lon": 39.4211, "kind": "ours" } ] }
```

`kind`: `ours` / `others` / `excluded`.

- [ ] **`mode = cells`** — кластер-кружок на каждую ячейку: размер ~ `log(total)`, число внутри; обводка — кольцо
      из двух дуг: фиолетовая доля `ours/total` и оранжевая `others/total` (+ серая `excluded`, если включено).
      При `client=ours` или `client=others` кружок одного цвета. Клик по кластеру → приблизить карту к нему на +2 зума.
- [ ] **`mode = points`** — маркер на компанию цветом по `kind`. Клик → карточка компании.
- [ ] Тепловой слой (по желанию, переключатель «Плотность»): из тех же `cells` — точка в центре ячейки с весом `total`.
- [ ] Старт: центр `[47.6, 40.8]`, зум 7 — вся Ростовская область.
- [ ] Подложка — растровые тайлы OSM. **Проверить на площадке, что грузятся**; если интернет режут — GeoJSON
      границ районов без подложки.
- [ ] Легенда: фиолетовый — наши клиенты, оранжевый — не наши, серый — исключены из реестра МСП.

### 5. Слои аналитики

| Слой | Источник | Логика |
| --- | --- | --- |
| Районы (переключатель «Потенциал») | `GET /api/municipalities/stats?industry=…` | заливка/кружок района по `potentialScore` 0→100; клик → панель района |
| Белые пятна | `GET /api/white-spots?industry=…&limit=10` | оранжевая пунктирная обводка района, в тултипе `reason` |

Панель района: название, действующих компаний, наших клиентов, доля охвата, исключённых клиентов, суммарная
выручка, потенциал, кнопка «Показать компании района» (ставит `municipalityId` в фильтр).

### 6. Список, синхронный с картой

- [ ] Справа (на телефоне — вкладка «Список») — `GET /api/companies?<фильтр с границами окна>&page&size=50&sort`.
      Сдвинул карту — список пересчитался, как список ПВЗ в окне.
- [ ] Колонки: название, отрасль, населённый пункт, категория, выручка (бейдж «оценка» при `isEstimated`), рост,
      метка «наш» / «не наш» / «исключён» цветом. Сортировка: `name`, `revenueEst`, `revenueGrowthEst`, `employees`, `registeredAt`.
- [ ] «Найдено: N» из `total` (в окне карты). Пусто → «В этой области ничего нет — отдалите карту или ослабьте фильтры».
- [ ] Клик → `GET /api/companies/{id}` → карточка: все поля, ИНН с копированием, статус, контакты, источник выручки
      («ФНС» / «оценка»); маркер компании подсвечивается на карте.

### 7. Панель фильтров

- [ ] **Наши / Не наши / Все** — три кнопки, всегда на виду (это главный переключатель).
- [ ] Отрасль (мультиселект), выручка от–до (млн руб. → рубли в запросе), район/город (мультиселект с поиском),
      категория, рост от (%), «Только новые», поиск по названию/ИНН, «Показывать исключённых из реестра» (`status=all`).
- [ ] «Сбросить». На телефоне — нижняя выезжающая панель.

### 8. Экспорт и загрузка клиентов

- [ ] «CSV» и «В CRM» → `fetch('/api/export/companies?' + filterToQuery() + '&format=csv|bitrix')` с токеном → `blob` →
      скачивание с именем из `Content-Disposition`. Перед скачиванием показать «Будет выгружено N компаний» (из `total`);
      при 413 — «Слишком много, сузьте фильтр».
- [ ] Пресет «Исключённые клиенты» — ставит `client=ours&status=excluded`: на карте и в списке только они, экспорт
      выгружает их же. Это список на чистку CRM.
- [ ] «Обновить список клиентов» (для админа): CSV → `POST /api/clients/import` → показать `matched`, `notFound`,
      инвалидировать кэш карты, списка, статистики.

### 9. Состояния

- [ ] Скелетоны, тост с `error.message`, 502 → «Сервис временно недоступен».

## Готово, когда

Демо-сценарий из 00-common проходится на телефоне и в трёх браузерах на настоящем API (MSW выключен), в образе nginx
после `docker compose up -d --build` — без ручных шагов; карта на всей области открывается быстрее 1 секунды.
